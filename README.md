# オリジナルナンプレ

5*5のオリジナルのナンプレが遊べるwebページのgithubリポジトリです。

## 遊び方

・左のサイドバーで難易度選択ができます
・ページを起動すると盤面が生成されゲームが開始されます
・マスを選択し、画面の数字パッドまたはキーボードで1~5の数字を入力します
・ヒントが欲しくなったら「ヒント」を押すとアシスタントがヒントを教えてくれます
・全部の盤面が埋まったら「答え合わせ」を押し、正解・不正解を確認できます
・どこかで間違えて詰まったら「最初から」を押すと元の盤面に戻ります
・次の盤面に進みたいときは「新しい盤面」を押すと新しいパズルがスタートします

## 技術

・主にHTML/CSS/JavaScriptで構成されています
・作成にあたりAIを使っています
・盤面生成/ヒント機能について専用のAIを使っています
